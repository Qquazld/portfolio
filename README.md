# Yann Letertre — Web Developer Portfolio

**Live site:** [yannletertre.netlify.app](https://yannletertre.netlify.app)

[Repository](https://github.com/Qquazld/portfolio)

## Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **NPM**

## Installation

To run locally:

```bash
# 1. Clone the repository
git clone https://github.com/Qquazld/portfolio.git
cd portfolio

# 2. (If using build tools) Install dependencies
npm install

# 3. Start the dev server or open index.html
npm run dev
# or simply open index.html in your browser (if no build step)
```
